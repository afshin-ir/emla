# اَفرا ۱٫۱٫۱ — اصلاح چیدمان انگلیسی

## اصلاح کارت‌های جست‌وجوی انگلیسی

- عنوان اصلی انگلیسی و صورت‌های دیگر انگلیسی اکنون واقعاً چپ‌چین و چپ‌به‌راست نمایش داده می‌شوند.
- قلم سادهٔ سامانه برای متن لاتین حفظ می‌شود و قلم وزیرمتنِ فارسی روی آن بازنویسی نمی‌شود.

## نصب و به‌روزرسانی

- این APK با همان کلید انتشار نسخۀ ۱٫۱٫۰ امضا شده است و می‌تواند روی آن به‌روزرسانی شود.
- اگر نسخۀ ۱٫۰٫۰ را پیش از جایگزینی فایلِ امضاشدۀ نهایی نصب کرده باشید، ممکن است برای گذر به نسخۀ امضاشدۀ فعلی لازم باشد آن نسخۀ قدیمی را یک بار حذف کنید؛ پس از آن، به‌روزرسانی‌ها با امضای ثابت انجام می‌شوند.
