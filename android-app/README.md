# اپ اندرویدی واژگان مصوب فرهنگستان

این پروژه یک اپ بومی اندروید است؛ برای نمایش صفحه‌ها از WebView استفاده نمی‌کند و PWA نیست.

- جست‌وجوی واژگان مصوب فرهنگستان و مدخل‌های فرهنگ املایی خط فارسی
- ذخیرۀ داده‌ها در پایگاه‌دادۀ SQLite داخل اپ
- جست‌وجو پس از نصب، بدون نیاز به اینترنت
- بسته‌بندی داده‌های به‌روز سایت در APK هنگام ساخت

## ساخت APK

پیش‌نیازها: JDK 17، Android SDK و Gradle 8.9.

از ریشۀ مخزن اجرا کنید:

    gradle --no-daemon -p android-app assembleDebug

در نخستین اجرا، داده‌های همراه اپ به پایگاه‌دادۀ محلی وارد می‌شوند. ساخت خودکار GitHub Actions نیز APK آزمایشیِ قابل نصب را به‌صورت artifact منتشر می‌کند.
