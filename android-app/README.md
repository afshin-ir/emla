# اپ اندرویدی واژگان مصوب فرهنگستان

این پروژه یک اپ بومی اندروید است؛ برای نمایش صفحه‌ها از WebView استفاده نمی‌کند و PWA نیست.

- جست‌وجوی آفلاین در واژگان مصوب فرهنگستان و مدخل‌های فرهنگ املایی خط فارسی
- فیلتر جداگانۀ هر بخش یا جست‌وجو در هر دو بخش، همراه با گزینۀ «تطبیق دقیق واژه»
- نمایش حوزه‌ها با نام کامل و نمایش شمارۀ دفتر با اعداد فارسی
- ذخیرۀ داده‌ها در پایگاه‌دادۀ SQLite داخل اپ؛ پایگاه‌داده از پیش هنگام ساخت APK آماده می‌شود و در نخستین اجرا فقط در حافظۀ اپ کپی می‌شود.

## ساخت APK

پیش‌نیازها: Python 3، JDK 17، Android SDK و Gradle 8.9.

از ریشۀ مخزن اجرا کنید:

    python3 android-app/scripts/build_database.py
    gradle --no-daemon -p android-app assembleDebug

ساخت خودکار GitHub Actions نیز APK آزمایشیِ قابل نصب را به‌صورت artifact منتشر می‌کند.
