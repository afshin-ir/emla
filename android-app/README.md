# اپ اندرویدی واژگان مصوب فرهنگستان

این پروژه یک اپ بومی اندروید است؛ برای نمایش صفحه‌ها از WebView استفاده نمی‌کند و PWA نیست.

- جست‌وجوی آفلاین در واژگان مصوب فرهنگستان، مدخل‌های فرهنگ املایی خط فارسی و متن کتاب «دستور خط فارسی»
- فیلتر جداگانۀ واژگان مصوب، فرهنگ املایی و دستور خط، همراه با گزینۀ «تطبیق دقیق واژه»
- نمایش لوگوی اَفرا در سربرگ و دسترسی به «دربارهٔ اَفرا» و منابع از منوی همبرگری
- نمایش شمارهٔ نسخه، نام سازنده و کانال تلگرام در بخش «دربارهٔ اَفرا»
- معرفی منابع اپ: واژگان مصوب فرهنگستان (دفترهای ۱ تا ۲۰)، کتاب «فرهنگ املایی خط فارسی» و کتاب «دستور خط فارسی»
- نمایش حوزه‌ها با نام کامل و نمایش شمارۀ دفتر با اعداد فارسی
- نمایش برابرهای انگلیسی به‌شکل برچسب؛ برجسته‌کردن واژۀ جست‌وجوشده در متن دستور خط و بازوبستن بندهای بلند
- صفحه‌بندی نتایج با شمار واقعی نتیجه‌ها و دکمۀ بارگذاری بیشتر
- جست‌وجوهای اخیر و نشان‌شده‌ها با ذخیره‌سازی محلی، کپی یا اشتراک‌گذاری مدخل و تنظیم اندازۀ نوشته
- راهنمای نمونه برای شروع جست‌وجو و نشانگر پیشرفت هنگام آماده‌سازی پایگاه
- ذخیرۀ داده‌ها در پایگاه‌دادۀ SQLite داخل اپ؛ پایگاه‌داده از پیش هنگام ساخت APK آماده می‌شود و در نخستین اجرا فقط در حافظۀ اپ کپی می‌شود.

## ساخت APK

پیش‌نیازها: Python 3، JDK 17، Android SDK و Gradle 8.9.

از ریشۀ مخزن اجرا کنید:

    python3 android-app/scripts/build_database.py
    gradle --no-daemon -p android-app assembleDebug

ساخت خودکار GitHub Actions نیز APK آزمایشیِ قابل نصب را به‌صورت artifact منتشر می‌کند.
