# دستور خط فارسی

نسخۀ جست‌وجوپذیر کتاب «دستور خط فارسی» از فرهنگستان زبان و ادب فارسی. متن کتاب، مقدمه‌ها، قواعد، مثال‌ها، توضیحات، جدول‌ها و نمایه در این سایت گنجانده شده است.

## قابلیت‌ها

- جست‌وجوی سراسری در متن کامل کتاب و جدول‌ها
- یافتن هم‌زمان عبارت و واژه‌ها با یکسان‌سازی شکل‌های رایج حروف فارسی و عربی
- فیلتر نتیجه‌ها بر اساس قاعده و توضیح، مثال یا جدول
- پیوند مستقیم هر نتیجه به محل آن در فصل مربوط
- نمایش سازگار با تلفن همراه و رایانه

## انتشار

مخزن با GitHub Pages قابل انتشار است. در تنظیمات مخزن، بخش **Pages** را باز کنید و شاخهٔ `main` و پوشۀ ریشه (`/`) را برای انتشار برگزینید.

## منبع متن

متن از فایل کتاب «دستور خطّ فارسی (ویراست دوم)» استخراج شده است. این نسخه برای مطالعه و جست‌وجو آماده شده؛ صفحه‌بندی چاپی کتاب بازسازی نشده است.
